# Campo Pronto ADS

Confirmed by owner 2026-09-21. Premium is a separate future application, not an annual plan in ADS.

- Manual credit adjustments and nonzero opening balances require the freshly authenticated global administrator.
- Venue managers may set packages and prices but cannot grant/remove credits or approve legacy recharge requests.
- Existing balances, historical requests and booking refund behavior are retained.
- Fixed intended reward: two videos per credit, one reward credit per user/venue/day.
- Package split remains 90% venue / 10% platform before processing fees.
- Annual/no-ad preferences are no longer offered or accepted, including stale stored settings.
- AdMob verified rewards and actual Stripe purchases remain unconnected; availability flags stay false. This release enforces access rules and shows truthful unavailability, not a completed monetization integration.
- Demo simulations remain explicitly separate from real venue balances.
- Web/PWA branding changes only. App Store metadata and native display name require a subsequent release.
